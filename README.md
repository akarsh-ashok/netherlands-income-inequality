# Income Inequality in the Netherlands (1980–2023)

## Project Overview
This project analyses income inequality in the Netherlands from 1980 to 2023 using data from the **World Inequality Database (WID.world)**.

The analysis was conducted using Microsoft Excel, focusing on income distribution before and after taxes and government transfers.

## Objectives
- Calculate pre-tax and post-tax Palma ratios.
- Examine the redistributive impact of taxes and government transfers.
- Analyse income shares of the bottom 10%, bottom 50%, top 10%, and top 1%.
- Visualise changes in income inequality over time.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Excel formulas
- Line charts
- World Inequality Database (WID.world)

## Methodology
The Palma ratio is calculated as:

**Palma Ratio = Top 10% Income Share / Bottom 50% Income Share**

The reduction in the Palma ratio is calculated as:

**Reduction (%) = (Pre-tax Palma − Post-tax Palma) / Pre-tax Palma × 100**

## Key Findings
- The Palma ratio was lower after taxes and transfers in all four benchmark years.
- Redistribution reduced the gap between the top 10% and bottom 50%.
- The redistributive effect varied over the period 1980–2023.
- The annual income-share analysis shows changes in the distribution of income over time.
